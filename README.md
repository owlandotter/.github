# .github

The organisation profile and the default community files for every Owl & Otter repo.

- `profile/README.md` is the page at [github.com/owlandotter](https://github.com/owlandotter).
- `SECURITY.md`, `SUPPORT.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md` and the issue and pull request templates apply to any repo that doesn't have its own.
