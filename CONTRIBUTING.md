# Contributing

Thanks for wanting to help. We don't take outside pull requests yet, unless we've asked for one.

If you've found a bug or have an idea, open an issue in the repo it's about, or email [support@owlandotter.app](mailto:support@owlandotter.app). Talk to us before you write code, so your time isn't wasted.

Security problems go through [SECURITY.md](https://github.com/owlandotter/.github/blob/main/SECURITY.md), never a public issue.

Everyone taking part follows our [code of conduct](https://github.com/owlandotter/.github/blob/main/CODE_OF_CONDUCT.md).
